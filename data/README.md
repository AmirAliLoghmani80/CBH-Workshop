# Class data files

Put these three files in this folder (not in a subfolder). The notebooks download them automatically from
`https://raw.githubusercontent.com/AmirAliLoghmani80/CBH-Workshop/main/data/`.

| File | Made by | Used by |
| --- | --- | --- |
| `ccle_panel.csv` | `prepare_ccle_panel` (last cell of the Notebook 2 instructor notebook) | Notebooks 2 and 3 |
| `ccle_mutations.csv` | same cell | Notebook 3 |
| `ccle_multiomics_panel.csv` | saved by Notebook 2, Part 4 (run with `ccle_panel.csv` present) | Notebooks 4 and 5 |

Source: DepMap (release 26Q3) and Nusinow et al. 2020. Check the DepMap terms of use before sharing publicly.
